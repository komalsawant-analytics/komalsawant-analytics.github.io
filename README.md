# Komal Sawant — Data Portfolio

📊 **Live interactive portfolio:** https://komalsawant-analytics.github.io

Three sample projects for D2C and retail businesses. **All brands and data are fictional and simulated.** The code, logic and outputs are real and run end to end.

| Project | Business problem | Result |
|---|---|---|
| [P1 · D2C Unified Profit Dashboard](p1_d2c_profit/) | 5 exports (Shopify, Amazon, a beauty marketplace, Meta Ads, product master) with no common product code | One star-schema model with true profit per product and channel after discounts, fees, returns, logistics, product cost and ads |
| [P2 · Weekly Store Report on Autopilot](p2_report_automation/) | 4 stores send POS files in 4 different formats every Monday | One command builds a formatted Excel report with live formulas, reorder alerts and an email summary |
| [P3 · AI-Ready Product Catalogue](p3_ai_ready_catalogue/) | Website catalogue export full of HTML and free text; a chatbot built on it would guess | Typed product data, a 127-entry grounded Q&A knowledge base and a human review queue |

Requirements: Python 3.10+, `pip install pandas openpyxl`.
